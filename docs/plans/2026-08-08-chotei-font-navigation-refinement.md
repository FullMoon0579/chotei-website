# CHOTEI 字体、导航与标题精修

## 视觉方向

导航从首屏开始使用白色半透明遮罩和黑色新版 Logo，下滑后只改变遮罩明度与模糊程度，不增加底部边线。全站内置 Klee One SemiBold 600，避免因访客设备没有安装字体而产生视觉差异。

## 细节调整

- 新版黑色横式 Logo 用于白色导航，白色文件保留为深色背景版本。
- 首屏下滑提示由静态线改为循环向下流动的高光线；页面开始滚动后整体淡出并下移消失。
- 所有竖排板块标题统一采用 Klee One 600，减少字距；标题引导线由 1px 加粗为 2px，并拉长至 84px，增加标题与线条间距。
- 预约区继续采用参考图中的深黑底，标题线条使用相同新规范，维持白色品牌标识和高对比预约入口。
- 尊重系统“减少动态效果”设置，关闭下滑提示动画与其他非必要过渡。
