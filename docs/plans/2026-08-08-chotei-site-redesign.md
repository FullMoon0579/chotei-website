# 長亭官网改版设计

## 目标

依据《長亭官网_需求倒推梳理.xlsx》重构现有单页品牌官网。视觉参考明寂官网的日式高级感，但内容、摄影与品牌叙事全部属于長亭。所有网站摄影仅使用用户提供的四个照片文件夹，并统一转换为响应式 WebP。

## 页面结构

1. 透明吸顶导航与全屏吧台首屏，突出“中國料理の技で、四季を奏でる”。
2. 深色非对称“長亭由来”与料理哲学，使用慢节奏文字揭示。
3. 白底四季料理图库，支持春夏秋冬切换与手动分页。
4. 四面板菜单与套餐，桌面端悬停扩展，移动端横向浏览，点击后展示对应套餐信息。
5. 通栏店铺空间轮播，每三秒切换，可手动操作与暂停。
6. 大留白店铺信息，电话、地图与地址可点击。
7. 深灰预约区，直达一休预约页面，并提供预约注意事项。
8. 极简页脚、公告入口与日英中语言切换。

## 内容与交互

整站以日语为默认，英语与中文切换后同步替换导航、标题、正文、菜单、店铺信息和预约文案。料理图库默认不自动播放；空间图库按需求每三秒自动轮播，鼠标悬停或用户启用降低动态效果时暂停。所有按钮具备键盘焦点样式，图片均包含可本地化的替代文本。

## 验证

构建检查覆盖服务端渲染、三语入口、预约外链、电话与地图链接、四季图库数据和真实图片路径。CSS 提供桌面、平板与手机布局，并尊重 `prefers-reduced-motion`。
