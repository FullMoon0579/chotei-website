# CHOTEI 交互与字体精修

## 核心判断

页面高级感不足的原因不是元素太少，而是状态下划线、过大的字距、跨语言英文标签和同时替换的轮播制造了视觉噪音。本轮将文字恢复到更接近日本料亭官网的明朝体比例：适当放大、减少字距、提高字重，以留白而非装饰表现层级。

## 调整方案

- 导航、语言和季节状态取消下划线，仅通过字重与明度区分；滚动导航使用暖灰半透明遮罩，不增加底部细线。
- 移除当前语言之外的英文标签、地点英文、英文按钮与页尾英文标语。
- 店铺画廊使用包含首尾克隆项的真实横向轨道，每 2.5 秒向左移动一张；桌面显示中央完整画面与两侧预览，手机显示单张。
- 套餐区改为白底。四张主图分别对应鱼翅、鲍鱼、佛跳墙、熊掌高级套餐；基础套餐仅以四个价格作为入口。
- 所有套餐入口打开同一个无障碍详情层。详情层使用淡雅芥子黄色、黑色明朝体、套餐名和菜品清单，点击背景、关闭按钮或 Esc 均可关闭。
- 地图入口统一指向長亭 CHOTEI 的正式 Google Maps 页面；预约主标题与按钮统一改为当前语言中的“预约”，保持一休跳转地址不变。
