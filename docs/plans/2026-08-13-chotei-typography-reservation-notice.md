# CHOTEI typography and reservation notice

## Direction

- Replace Klee One with the free, OFL-licensed Shippori Mincho Regular.
- Use the font at a restrained regular weight with the generous tracking seen on the reference restaurant site.
- Keep brush-script logos as image assets; apply the new typeface to all navigational, editorial, course, store, and reservation text.
- Add a bordered "お客様へのお知らせ" action inside the dark reservation panel.
- Present the notice in a white, vertically scrollable modal with a quiet editorial layout, a fixed close control, backdrop dismissal, and Escape-key support.
- Localize the notice for Japanese, English, and Chinese so language switching remains complete.

## Validation

- Verify the production build and lint pass.
- Assert that the new local font and reservation notice controls are present.
- Publish the validated build to the existing CHOTEI site.
