# CHOTEI 官网第二轮视觉精修

## 设计方向

本轮采用“白纸、墨色、留白、静态秩序”的日式高级餐厅语言。正式品牌 Logo 取代所有文字模拟标识；字体以明朝体为主，通过字距、细线和比例建立精致感，而不是增加装饰。

## 交互与结构

- 导航首屏保持透明白字，页面下滑后切换为带轻微透明度的白色遮罩、黑字与细底线。
- 四季料理保留春夏秋冬文字标签，删除菜名、圆点和图片按钮；每季三张实拍菜品以慢速叠化自动轮播。
- 长亭由来与料理哲学统一为白色编辑式版面，利用大标题、长行距与留白呈现品牌故事。
- 空间和店铺信息合并为“店铺”板块。上方采用左右窄图、中央宽图的自动轮播画廊；下方使用正式竖式 Logo 和居中店铺信息，不显示轮播按钮或图片标题。
- 预约板块改为深墨色礼宾式版面，以正式白色 Logo、预约主按钮、注意事项和电话构成清晰层级。

## 响应式与无障碍

桌面端维持大幅留白和三联画构图；手机端将画廊收束为单张大图，导航改为白底抽屉。自动轮播在用户开启“减少动态效果”时停用。季节标签、语言选择、预约、电话和地图保持键盘可操作与语义标注。
